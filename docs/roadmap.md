# 목표와 완료 기준

최종 결과물은 엔진을 가상 공간에서 조작하고, 센서로 상태를 갱신하며, 시나리오별 성능·수명 결과를 근거와 함께 비교하는 프로그램입니다.

## 1단계 · 가상 엔진 실험실 — 첫 구현 완료

- 3D 개념 형상, 팬/압축기/터빈 회전 표현
- 정상상태 열역학 모델, 입력 조절, CSV 결과
- 에너지 보존·변수 범위·기본 경향 테스트
- 가정과 검증 범위를 문서화

## 2단계 · 시뮬레이션의 신뢰도 개선

- 독립 기준 계산과 대표 운전점 수치 비교
- 고정 노즐 초킹/압력 추력, 부품 맵과 유량 매칭 도입 검토
- 관성·열 응답 모델을 추가해 입력 변화의 과도응답 구현
- 동일 시나리오 재현, 단위·보존식·수치 수렴 확인
- CFD는 별도 고급 목표로 관리하고, 입자 애니메이션과 구분

## 3단계 · 엔진 개체와 센서 연결

- C-MAPSS FD001 정식 배포본 및 생성 논문 검토
- 엔진 ID, 운전 사이클, 관측값, 추정값, 데이터 출처를 별도 보관
- 데이터 재생 → 관측 갱신 → 상태 추정 → 화면 반영
- 합성 개념 엔진과 C-MAPSS를 별도 모드로 제공
- 모델/관측 매핑이 검증된 항목만 동기화

## 4단계 · 상태·수명 예측

- 단순 기준 모델 → 개선 모델 순서로 비교
- 엔진 단위로 검증 집합을 분리해 데이터 누수 방지
- 학습에서 보지 않은 엔진의 RUL 오차와 불확실성 평가
- 미래 운전 조건 변경의 수명 효과는 검증된 열화 모델이 있을 때만 표시

## 5단계 · 최종 시연

- 정상/효율 저하/관측 이상 시나리오 비교
- 재현 가능한 설정·결과 파일·실행 방법·시연 영상 제공
- 어떤 결과가 물리 계산, 데이터 예측, 설명용 표현인지 화면에 표시

기술 시작점은 Python + NumPy + Matplotlib입니다. 브라우저 공유가 필요해지면 Python 계산 엔진을 유지하고 3D 웹 뷰어 또는 별도 렌더러를 연결할 수 있습니다.
