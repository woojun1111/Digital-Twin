# 모델 v0.1: 무엇을 계산하는가

## 경계와 단위

입력은 운전 명령 u, 고도 h [m], 비행 Mach, 압축기 효율의 상대 손실입니다.
출력은 전온도 [K], 전압력 [Pa], 질량 유량 [kg/s], 힘 [N]입니다.
가상 엔진은 별도 배기형 터보팬의 교육용 집중정수 모델입니다. 실제 기종을 재현하지 않습니다.

## 계산 순서

1. 대류권 표준대기 근사: T = 288.15 − 0.0065h, p = 101325(T/288.15)^(g/R/L).
2. 비행 Mach로 입구 전온도·전압력을 계산하고 입구 압력 회복률 0.99 적용.
3. 팬/압축기: Tout = Tin[1 + (PR^((γ−1)/γ) − 1)/η].
4. 연소기: 지정 출구 전온도 T4에 도달하는 연료/공기비 f = cp(T4−T3)/(ηb·LHV−cp·T4).
5. 코어 유량 기준 축 일량 W = cp[(T3−Tfan) + (1+BPR)(Tfan−T2)]. 팬은 코어와 바이패스 공기를 모두 처리합니다.
6. 터빈: (1+f)cp(T4−T5)ηm = W. 터빈 효율로 전압력 감소 계산.
7. 두 노즐을 주변 압력까지 팽창시킨 속도를 각각 계산. 출구 압력=주변 압력 가정으로 압력 추력은 0.
8. F = mcore[(1+f)Ve−V0] + mbypass(Vb−V0).

## 프로젝트가 선택한 가정 — 논문에서 추정한 실측값이 아님

| 항목 | 값 / 식 |
|---|---|
| 비열·비열비 | cp=1004.5 J/(kg K), γ=1.4, 연소가스에도 동일 적용 |
| 연료 저위발열량 | 43 MJ/kg |
| 바이패스비 | 5 |
| 팬 압력비 | 1.08 + 0.42u |
| 코어 압축기 압력비 | 3 + 12u |
| 팬/압축기 기준 효율 | 0.90 / 0.88 |
| 압축기 효율 저하 | 0.88 × (1−loss) |
| 연소기 출구 전온도 | 1000 + 500u K |
| 연소기 압력비 / 효율 | 0.95 / 0.99 |
| 터빈 / 축 / 노즐 효율 | 0.91 / 0.99 / 0.97 |
| 코어 유량 | 20(0.5+0.5u) × (Pt2/101325) / sqrt(Tt2/288.15) kg/s |

효율 손실은 사용자가 주는 민감도 변수입니다. 자동 열화 법칙, 고장 확률, 잔여 수명으로 해석하지 않습니다. 운전 명령이 바뀔 때 압력비·출구 온도·유량을 함께 바꾸는 가정이며, 엔진 부품 맵이나 FADEC 제어기를 푼 결과가 아닙니다.

## 적용 범위와 다음 검증

- 고도 0–11 km, Mach 0–0.85, 운전 명령 0.2–1, 효율 손실 0–0.15.
- 노즐은 완전 팽창하는 가변 형상 근사입니다. 고정 노즐의 초킹·면적 매칭을 예측하지 않습니다.
- 회전 관성, 축별 동역학, 서지, 냉각 유량, 가변 비열, 열전달, 진동, 구조 응력, CFD는 미구현입니다.
- 형상과 입자는 설명용입니다. 형상에서 유량·압력장·RPM을 계산하지 않습니다.
- 에너지 보존 테스트는 구현 검증이며 실제 엔진 정확도 검증과 다릅니다.
- 다음 검증은 명시된 동일 조건의 독립 기준 계산/공개 성능값과 비교하는 것입니다. 허용 오차와 보정 근거를 함께 기록해야 합니다.

온도는 전온도입니다. 터빈 출구 전온도를 특정 실제 엔진의 EGT 센서값으로 이름만 바꿔 쓰지 않습니다.
