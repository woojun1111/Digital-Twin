# v0.3 실행 및 실험

Edge 또는 Chrome에서 배포 주소를 열거나 `web/index.html`을 엽니다. Windows에서는 `open-web.cmd`를 더블클릭합니다. 라이브러리가 함께 제공되므로 외부 CDN이나 Python 설치가 필요 없습니다. WebGL 지원과 그래픽 가속이 필요합니다.

1. 단면을 켜고 드래그해 팬, 압축부, 연소기와 터빈을 살펴봅니다.
2. 부품을 클릭하거나 하단 모듈 버튼으로 선택합니다. 분해 슬라이더는 부품 그룹을 축 방향으로 벌립니다.
3. 운전 명령을 올리면 N₁/N₂가 시간차를 두고 반응합니다. 실제 RPM이 아니라 정규화된 교육용 상태입니다.
4. 후연소 표현은 열·노즐 반응 예시입니다. 실제 점화 과정과 제어기를 재현하지 않습니다.
5. 그래프를 가스/금속 온도로 바꾸고 엔진을 정지하면 서로 다른 냉각 속도를 볼 수 있습니다.
6. 가속·감속 또는 가열·냉각 자동 실험을 실행할 수 있습니다. 수동 입력을 바꾸면 자동 실험이 종료됩니다.
7. 기준선을 저장하고 초기화한 뒤 효율 손실을 바꿔 동일 실험을 실행하면 점선과 비교됩니다. 기준선은 현재 페이지 메모리에만 유지됩니다.
8. CSV는 최근 최대 12,000개 시점(10Hz, 약 20분)의 교육용 상태와 입력을 저장합니다. 시간은 시뮬레이션 시간이며 배율에 따라 실제 시간과 다릅니다.

일시정지는 모델 시간, 축과 입자의 움직임을 함께 멈춥니다. 카메라는 계속 움직일 수 있습니다. 다른 탭으로 이동하면 계산을 정지해 보이지 않는 동안 시뮬레이션 시간이 뛰지 않게 합니다. 전체 화면은 Escape 또는 화면 내 닫기 버튼으로 종료합니다.

그래픽 오류 시: Edge/Chrome 업데이트, 그래픽 가속 사용 여부, 전체 ZIP 압축 해제 여부를 확인합니다. 수치 계산 UI는 3D 초기화 실패 시에도 유지됩니다.

CSV 열: time [s], throttle [0–1], running [boolean], loss [상대 손실], ambient [K], lp/hp [정규화 %], gas/metal/compressor/exhaust [K, 교육용], pressureRatio [교육용], response [무차원], fuel/nozzle/augment [무차원]. 파일의 model_kind는 educational_reduced_order입니다.
