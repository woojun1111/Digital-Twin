# F414 구조 참고 및 교육용 동특성 v0.3

조사일: 2026-11-16 (한국 시간). 본 버전은 F414-GE-400의 공개 구조를 참고한 시각화에 일반적인 축약 응답 모델을 연결한 교육용 실험실입니다. 제조사의 설계/성능 모델이 아닙니다.

## 형상의 근거 수준

외형 길이와 지름, 두 축 및 후연소·노즐 구성은 공개 자료에 근거합니다. 내부 단별 길이, 팬 3열/압축부 7열/터빈 2열 표현, 날개 수, 날개의 비틀림·두께, 노즐 플랩 18개, 배관 경로, 체결부는 첨부 이미지와 공개 구조를 참고한 **절차적 시각화 근사**입니다. 제작·정비용 CAD가 아닙니다. 사진을 역설계해 실제 내부 치수를 얻었다고 주장하지 않습니다.

## 부족한 자료

F414의 회전수별 압축기/터빈 맵, 축 관성, 냉각·추기 유량, 열용량, FADEC 제어 로직, 부품 치수 도면, 계측 시점별 검증 데이터는 확보하지 못했습니다. 따라서 본 버전에서 실제 RPM·연료 유량·추력을 산출하지 않으며 N₁/N₂와 응답 지수는 정규화 값으로 표시합니다. C-MAPSS는 F414 데이터가 아니므로 이 모델의 검증에 혼용하지 않습니다.

## 물리 모델의 범위

`model.js`는 일반 원리를 보여주는 축약 모델입니다.

- 두 축의 정규화 에너지 상태 E=N²를 서로 다른 시간상수로 목표 상태에 접근시킵니다.
- 상수 목표에 대해 E(t+dt)=E_target+(E(t)−E_target)exp(−dt/τ)를 사용합니다.
- 연료 지수, 가스 온도, 노즐 개방도도 1차 지연을 갖습니다.
- 금속 온도는 집중 열용량 대류 근사 dTm/dt=(Tg−Tm)/τm로 갱신합니다.
- 압축기 온도 예시는 일정 비열 이상기체 관계를 사용하되 압력비·효율은 임의 교육용 계수입니다.
- 응답 지수는 축 상태와 효율 손실에 종속된 무차원 시각화 지표이며 운동량으로 계산된 추력이 아닙니다.
- 시각화의 입자·화염은 CFD가 아닙니다. 물리 상태에 반응하지만 속도·온도장의 해는 아닙니다.

시간상수(초): 저압 상승 3.6, 고압 상승 1.9, 저압 감속 7, 고압 감속 4.5, 연료 0.7, 가스 0.9, 금속 22, 노즐 1.2. 모두 교육용 가정이며 F414 실측값이 아닙니다. 목표 속도와 온도 스케줄의 상수도 `model.js`에 명시한 교육용 선택입니다. 실제 토크 평형, 질량 유량 매칭, 전체 열역학 사이클을 해결하지 않습니다.

## 검증 결과

- 동특성 12개 검사: 지연, 정상 수렴, 정지·냉각, 시간 분할 일치, 0.01/0.005초 간격 수렴, 입력 범위, 후연소 표현 연동, 장시간 유한성.
- 단위 간격 차이 검사: 10초 응답에서 N₂ 차이 0.05 percentage point 미만, 금속 온도 차이 0.5 K 미만.
- 형상 검사: 176개 mesh/points 객체, 회전 날개열 12개, 노즐 플랩 18개. 좌표/법선 유한성, 분해, 단면, 열 표시, 선택 확인.
- 모의 DOM 검사: 시간 진행·정지, 입력, 초기화, 기준선 유지, 다운로드, 엔진 스위치, 출처 창, 자동 실험.
- 브라우저 제어 도구가 현재 세션에 없어 WebGL 화면, 실제 GPU 성능, 모바일 터치/다운로드는 직접 검증하지 못했습니다. 이는 숫자·동작 코드 검사와 별도의 미검증 영역입니다.

## 다음 신뢰도 향상 단계

공개된 일반 연구용 엔진 모델을 별도 기준으로 선정하고, 정상상태 부품 맵·유량 매칭·축 토크·열 모델을 단계적으로 검증할 수 있습니다. 새 기준 모델의 성능을 실제 F414의 성능으로 표기하지 않습니다. 로켓은 대기흡입 엔진과 다른 추진기관 모델이 필요하며, 향후 공통 3D·시간기록·환경 인터페이스를 재사용하는 별도 학습 모듈로 다룹니다.
