# v0.4 — 일반 엔진 0D 사이클과 열수지

2026-11-17. **F414 외형을 참고한 화면에 연결된 일반 교육용 물리 모델**입니다. F414 성능 모델 또는 실기 데이터로 검증된 디지털트윈이 아닙니다.

## 이번에 실제로 달라진 계산

이전 온도 목표식 대신 팬 → 압축기 → 연소기 → 고압/저압 터빈 → 후연소기 → 노즐의 전온/전압을 계산합니다. 고압 터빈은 압축기 부하, 저압 터빈은 팬 부하와 준정상 축동력이 일치하도록 풀었습니다. 코어와 바이패스는 별도 배기입니다. 금속은 단일 열용량의 대류·복사 열수지로 적분합니다.

축 속도는 여전히 가정한 시간상수로 움직입니다. **J·ω·dω/dt = 터빈동력 − 부하동력**으로 가속을 계산한 모델이 아닙니다. 대수적 축동력 잔차가 작다는 것은 구성 방정식을 만족한다는 뜻이며, 과도운동의 에너지 보존이나 실기 정확도 증거가 아닙니다.

## 계산식과 단위

SI 단위: K, Pa, kg/s, W, m². cp = 1004.675 J/(kg K), R = 287.05 J/(kg K), γ = 1.4로 일정하며 cp = γR/(γ−1)입니다. 고온 연소가스에도 같은 물성을 쓰므로 특히 고온 정확도가 제한됩니다. 연료의 유입 현열은 0으로 둡니다.

1. 압축: Tout = Tin [1 + (PR^((γ−1)/γ) − 1)/ηc], Pout = Pin PR. 축부하 = ṁ cp ΔT. 팬은 코어+바이패스 전체 유량을 압축합니다.
2. 연소: Tout = [Tin + f ηb LHV/cp]/(1+f), ṁout = ṁair(1+f). 압력 손실은 고정 회복계수로 둡니다. 후연소기도 같은 질량/엔탈피 수지를 사용합니다.
3. 터빈: ΔT = Pload/(ṁhot cp ηshaft), Pout/Pin = [1−ΔT/(ηt Tin)]^(γ/(γ−1)). 물리적으로 정의되지 않는 팽창 상태는 유효하지 않다고 표시합니다.
4. 수축 노즐 근사: Pt/Pa ≥ [(γ+1)/2]^(γ/(γ−1))이면 출구 M=1. 그 외에는 Pe=Pa. Te=Tt(Pe/Pt)^((γ−1)/γ), Ve=√[2cp(Tt−Te)], Ae=ṁ/(ρe Ve), F=ṁVe+(Pe−Pa)Ae. 지상 정지 조건이므로 비행 운동량 항은 0입니다.
5. 금속: C dTm/dt = Hgas·N₂·(Tgas−Tm) − Hamb·(Tm−Tamb) − εσA(Tm⁴−Tamb⁴). 정지 시 고온가스 항을 0으로 둡니다. 적분은 explicit Euler, 최대 Δt=0.01 s입니다.

노즐 면적은 지정된 유량을 통과시키는 데 필요한 **역산 면적**입니다. 가변 기하 노즐로 유량을 폐쇄하는 해가 아니며 3D 플랩 개방 지수와 연결되어 있지 않습니다. 실제 F414의 혼합 유동 수축·확대 노즐과 다릅니다. 초음속 확대부, 충격파와 박리는 없습니다.

금속은 가스 계산 결과를 입력으로 받는 **단방향 열 모델**입니다. 금속으로 빠지는 열을 사이클 가스 엔탈피에서 빼지 않으므로 가스+고체 전체의 에너지가 보존되는 공액 열전달 해석은 아닙니다. 연소기와 축 잔차는 해당 대수 방정식만 검증합니다. 가스는 준정상 상태이며 연소실 저장 에너지·압력 축적은 없습니다.

## 일반 모델의 가정값 — F414 식별값 아님

| 항목 | 가정 |
|---|---|
| 환경 | 지상 정지, 101325 Pa, 주변온도 −20~40 °C |
| 기준 코어유량 / 바이패스비 | 20 kg/s / 0.4 |
| 유량 스케줄 | 코어유량 = 20 × 정규화 N₂ |
| 팬 / 압축기 압력비 | 1+0.8 N₁² / 1+8 N₂² |
| 팬 / 압축기 / 터빈 / 축 효율 | 0.88 / 0.86 / 0.90 / 0.99 |
| 연소 / 후연소 압력 회복 | 0.95 / 1−0.03×후연소 지수 |
| 발열량 / 연소 효율 | 43 MJ/kg / 0.98 |
| 주연료 공기비 | f = 0.008 min(1,u/0.12) + 0.018u, u는 지연된 연료 지수 |
| 후연소 추가 연료비 | 0.008 × 후연소 지수 (터빈 출구 질량유량 기준) |
| 금속 열용량 / 가스 열전달계수 H | 18000 J/K / 700 W/K × N₂ |
| 환경 열전달계수 / 방사율 / 면적 | 50 W/K / 0.7 / 0.8 m² |

운전 명령 → 연료 지수 지연 → 축 속도 지연 → 부품 압력비/유량 → 사이클 상태 → 금속 열상태 순으로 계산합니다. 모든 스케줄은 교육용으로 선택했으며 논문이 제공한 F414 계수가 아닙니다. 가정 유량이나 연료비를 바꾸면 추력 숫자도 바뀝니다. 정지 또는 계산 유효 조건을 만족하지 않을 때 추력 카드에는 `—`, 기록에는 cycleValid=false와 thrustKN=0이 들어갑니다. 이를 실제 정지 추력의 예측으로 해석하면 안 됩니다.

`node tests/physics.cjs web`: 이상 압축 해, 효율 방향, 비초크/초크 노즐의 질량·에너지, 초크 전환 연속성, 연소기·후연소기 에너지, 축동력 잔차, 열평형/냉각/이산 열수지, 정지 상태, 운전 범위, 0.01/0.005 s 수렴을 확인합니다. 기존 동특성·형상·모의 DOM 검사도 유지합니다.
